# Local media assets

This public repository does not include reference-derived images or videos.

Place or generate your own licensed media here. `scripts/build-video-states.ps1` creates:

- `video/sleep-loop.mp4`
- `video/wake.mp4`
- `video/awake-loop.mp4`
- `video/sleep-transition.mp4`

An optional local poster can be stored as `girl-awake.png`. These generated media files are intentionally ignored by Git.
